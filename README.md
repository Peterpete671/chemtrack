# CHEMTRACK

## Chemical Sample Data Management System

## What is Chemtrack?

It is a backend API for capturing, validating, and analysing chemical sample data.
It is built with Django REST Framework and Python

It combines chemistry domain language with software engineering; the system understands that an acid cannot have a pH above 7, and automatically flags it.

## What problem does CHEMTRACK solve?

Laboratory data is often recorded manually and inconsistently. Errors such as wrong pH, missing fundamental fields and incorrect units corrup analysis. This system enforces rules at the point of entry and surfaces anomalies automatically.

## How does CHEMTRACK work?

Input(POST) -> Validation -> Storage -> Analytics -> Output(GET)

1. Sample data is submitted via POST /api/samples/
2. Validation rejects impossible values (pH >14, conc <= 0 )
3. Cross-field rules catch logical contradictions (acid = pH 10)
4. Valid data is stored with an automatic timestamp
5. Summary and anomaly endpoints return computed insights

## Endpoints

| Endpoint           | Method | Description                            |
| ------------------ | ------ | -------------------------------------- |
| /api/samples/      | GET    | List all samples with optional filters |
| /api/samples/      | POST   | Add a new chemical sample method       |
| /api/samples/<id>/ | GET    | Retrieve one sample by ID              |
| /api/summary/      | GET    | Statistical summary by sample type     |
| /api/anomalies/    | GET    | Samples flagged as chemically unusual  |
| /api/health/       | GET    | System status and endpoint directory   |

## Data fields

| Field         | Type            | Rules                                  |
| ------------- | --------------- | -------------------------------------- |
| sample_name   | String          | Required, Follows TYPE-NUMBER-INITIALS |
| sample_type   | Enum            | acid, base, buffer, neutral, unknown   |
| pH            | Decimal         | 0.00 - 14.00, must maytch sample type  |
| concentration | Decimal (mol/L) | >0, unit fixed to mol/L                |
| temperature   | Decimal(C)      | Optional, -10 to 200                   |
| recorded_at   | Timestamp       | Autogenerated UTC                      |

## Anomaly detecton

The system flags three types of anomaly:

1. pH outside the expected range for the sample type
2. Concentration above 0.5mol/L (unusually high)
3. Temperature more than 2C from lab standard (25C)
